## 1. 产品概述

在线课堂是一个面向学习者的视频课程学习平台，支持课程浏览、章节导航、视频播放与学习进度追踪。目标用户为希望在线系统性学习的学员，核心价值在于提供流畅的视频学习体验与精准的学习进度管理。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 学员 | 邮箱注册 | 浏览课程、播放视频、查看学习记录 |

### 2.2 功能模块

1. **课程列表页**：课程封面、标题、总时长、学习人数展示
2. **课程详情页**：课程简介、章节目录树（课程 → 章 → 节）
3. **视频播放页**：视频播放/暂停、进度条、倍速切换(0.5–2x)、续播、进度上报、完成判定
4. **学习记录页**：我的课程列表、每门课最近学习节信息

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 课程列表页 | 课程卡片 | 展示封面图、标题、总时长、学习人数，支持点击进入详情 |
| 课程列表页 | 顶部导航 | 品牌标识、导航链接（课程列表、学习记录） |
| 课程详情页 | 课程简介 | 课程描述、封面图、统计信息 |
| 课程详情页 | 章节目录树 | 树形结构展示 章 → 节，节可点击进入视频播放 |
| 视频播放页 | 视频播放器 | 基于 Video.js，支持播放/暂停/进度条/倍速 0.5–2x |
| 视频播放页 | 续播功能 | 进入节时从上次 watchedSec 位置继续播放 |
| 视频播放页 | 进度上报 | 定时（每10秒）记录当前观看秒数 |
| 视频播放页 | 完成判定 | watchedSec / durationSec ≥ 90% 标记节已完成 |
| 视频播放页 | 侧边章节导航 | 当前章节目录，快速切换节 |
| 学习记录页 | 课程学习卡片 | 展示已学习课程、最近学习节名称、学习进度 |

## 3. 核心流程

**课程学习主流程**：学员浏览课程列表 → 点击课程进入详情 → 浏览章节目录 → 点击节进入视频播放 → 从上次位置续播 → 观看视频 → 系统定时上报进度 → 达到90%标记完成 → 返回详情或继续下一节

```mermaid

    "点击课程卡片" --> "课程详情页"
    "课程详情页" --> "点击节"
    "点击节" --> "视频播放页"
    "视频播放页" --> "从watchedSec续播"
    "从watchedSec续播" --> "观看视频"
    "观看视频" --> "定时上报进度"
    "定时上报进度" --> "是否≥90%"
    "是否≥90%" -->|"是"| "标记节完成"
    "是否≥90%" -->|"否"| "继续观看"
    "标记节完成" --> "继续下一节/返回详情"
    "学习记录页" --> "查看最近学习节"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深青蓝 (#0F4C5C) 作为品牌色，搭配暖橙 (#E36414) 作为强调色
- **背景风格**：浅灰暖色底 (#FAFAF8)，营造沉浸学习氛围
- **字体**：标题使用 Noto Serif SC（衬线体，学术感），正文使用 Noto Sans SC（清晰易读）
- **按钮风格**：圆角适中(6px)，主按钮实心填充，次要按钮描边
- **布局风格**：顶部导航 + 内容区域，卡片式布局
- **图标风格**：线性图标（Ant Design Icons），简洁统一

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 课程列表页 | 顶部导航 | 深色背景，品牌Logo居左，导航链接居右，悬停下划线动效 |
| 课程列表页 | 课程卡片网格 | 3列网格布局，卡片圆角阴影，封面图上方，信息下方，悬停微上浮 |
| 课程详情页 | 课程信息区 | 左侧大封面，右侧课程标题+描述+统计，底部章节目录树 |
| 课程详情页 | 章节目录树 | 手风琴式展开，章标题加粗，节标题带播放图标，已完成节打勾 |
| 视频播放页 | 视频播放区 | 左侧大区域视频播放器，右侧侧边栏章节导航 |
| 视频播放页 | 侧边章节导航 | 当前节高亮，已完成节打勾，可折叠章 |
| 学习记录页 | 学习记录卡片 | 卡片展示课程信息、最近学习节、进度条 |

### 4.3 响应式设计

- 桌面优先设计，最小宽度1024px
- 中等屏幕(768-1024px)：卡片2列，视频页侧边栏折叠
- 小屏幕(<768px)：卡片1列，视频页侧边栏隐藏为抽屉
